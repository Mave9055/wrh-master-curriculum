# WRH Participant Workbooks

## Phase 4 Purpose

This directory contains the **participant-facing implementation layer** for the WRH Core Spine. Each workbook translates a lesson into a practical format participants can read, write on, practice, and carry forward without changing the underlying lesson.

> The workbook should not become a second textbook. The Core Lesson explains what participants need to understand; the workbook asks, **“What does this look like when you apply it?”**

## Standard Workbook Shell

All participant workbooks use the same structured sequence.

| Section | Participant prompt or function |
|---|---|
| 1. Lesson Title | Plain-language introduction. |
| 2. What This Lesson Is About | One short participant-facing explanation. |
| 3. The Core Distinction | The single idea the participant needs to understand. |
| 4. Recognize | **What happens in me?** Include short checkboxes and writing space. |
| 5. Name | **What would I call what is happening?** Identify the behavior, reaction, assumption, or pattern. |
| 6. Explain | **What might be driving this response?** Explain without excusing. |
| 7. Separate | Use a two-column exercise: what belongs to me and what does not belong to me. |
| 8. Interrupt | **What can I do before the pattern takes over?** Identify an interruption point. |
| 9. Practice | Use a short scenario with space to write or rehearse a response. |
| 10. Accountability Check | **What part belongs to me?** |
| 11. Boundary Check | **What part does not belong to me?** |
| 12. Next Action | **What will I do differently?** Require a specific behavioral action. |
| 13. Carry-It Statement | End with a short statement participants can take with them. |
| 14. Self-Assessment | Use the standard Recognize / Own / Change scale. |
| 15. Optional Reflection | Clearly mark disclosure as optional. |

## Delivery Guardrails

The workbook preserves the WRH instructional engine:

> **Recognize → Name → Explain → Separate → Interrupt → Practice → Carry It.**

It also incorporates the Phase 2 action framework:

> **Accountability Check → Boundary Check → Next Action.**

All workbook content must remain plain-language, non-diagnostic, and free of forced disclosure. Batch 1 should be verified across Corrections, Reentry, Veteran, and Workplace settings before production moves to Lessons 9–16.
