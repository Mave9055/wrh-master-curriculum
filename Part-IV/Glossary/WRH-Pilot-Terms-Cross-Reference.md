## The Interrupt — harmonized wording

In pilot materials, **The Interrupt** is the moment when a participant recognizes the mechanism beginning to run and intervenes before the inherited loop completes. In the master curriculum, this function is expressed through **Pattern Veto** and **Loop Interrupted**: name the mechanism, create a brief micro-regulation pause, and choose a replacement action before the old pattern determines the next step.

**Use in the master curriculum:** Refer to **Pattern Veto** or **Loop Interrupted** as the authoritative terms. “The Interrupt” may appear parenthetically when explaining the pilot-source vocabulary, but it is not a standalone session, phase, or new master-curriculum term.

## The Driver — cross-reference only

The pilot source uses **The Driver** for the decision-making layer that can observe the system and choose a different action. Use the existing master-curriculum definition and usage wherever this concept appears. Do not add or overwrite a second glossary definition here.

## Ledger — cross-reference only

The pilot source uses **Ledger** for the system’s learned record of prior survival outcomes. Use the existing master-curriculum definition and usage wherever this concept appears. Do not add or overwrite a second glossary definition here.
